# 08 ｜ 國翠：三份報表整合成一個 Excel

## 📋 你的需求
整合系統下載的三個不同報表，內容格式轉換成想要的格式，並將三個檔案放入同一個 Excel 檔的不同工作表。

---

## 🛠️ 建議工具：**專案**

---

## 📦 你要準備的素材
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **三份報表各一份** | 系統下載的原始檔，不要先手動改過 | ★ 必備 |
| **目標格式範例** | ⭐ **最重要**：你理想中的成品長什麼樣 | ★ 必備 |
| **欄位改名對照表** | 原欄位名 → 你要的欄位名，逐項列出 | ★ 必備 |
| **要保留／刪除的欄位清單** | 三份報表各自要留哪些 | ★ 必備 |
| 一份人工做好的成品 | 可以直接驗證 AI 做得對不對 | 建議 |

> 💡 **如果你手上有一份自己做好的成品，那是最強的素材。**
> 把它放進專案，等於給了 AI 一個標準答案。
> 而且你可以拿它跟 AI 的結果逐格比對，**一次就知道它哪裡會出錯。**

---

## 🚀 建立專案步驟

1. 專案名稱：`三報表整合`
2. **專案指令**：直接複製 [`專案指令.txt`](./專案指令.txt) 貼上。
3. **專案檔案**：目標格式範例（Excel）、欄位改名對照表。

```
你負責把系統下載的三份報表整合成一個 Excel 檔。

【報表 A】
保留欄位：（列出）
欄位改名：（原名 → 新名，逐項列出）

【報表 B】
保留欄位：（列出）
欄位改名：（列出）

【報表 C】
保留欄位：（列出）
欄位改名：（列出）

【格式規則】
- 日期一律 YYYY-MM-DD
- 金額加千分位、不要小數
- 缺值填「-」，不要填 0

【輸出】
一個 xlsx 檔，四個工作表：A／B／C／彙總
彙總表：三份報表的總計並列，最後加一列「差異檢查」
```

---

## 💡 省額度的做法

三個檔剛好用掉你一整天的上傳額度，做錯就不能重來。

**建議：兩份用貼的、一份用傳的。**

（CSV 或純表格資料通常可以直接貼；只有需要保留複雜排版格式的才用傳的）

---

## ★ 每次都要做的驗證動作

> **核對：彙總表的總計 = 三份原始報表的加總**
>
> 這一步比任何提示詞技巧都重要。
>
> 資料轉換最常見的錯誤不是「格式跑掉」（那你一眼就看得出來），而是**漏了幾筆資料**——表格看起來完全正常，但總數少了。**只有對總數才抓得到。**
