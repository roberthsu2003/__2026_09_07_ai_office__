# 07 ｜ 盉語：素材準備檢核表

上課前請逐項確認素材是否已經準備好：

### 📗 規則類（放進專案檔案 / 專案指令）
- [ ] **事項分類清單（確定版）** ⭐必備：固定六大分類（場地設施／規費收費／證照與資格／流程行政／勞資人事／其他）。
- [ ] 會員名冊簡稱／代號對照（建議）：方便比對重複反映事項。

### 📘 範例類（放進專案檔案）
- [ ] **過去的理監事會報告範本** ⭐必備：讓 AI 學習公會報告的排版格式、語氣與公文措辭。

### 📙 資料類（每次貼上文字輸入）
- [ ] **一期的原始記錄（最亂的一期）** ⭐必備：
  - [ ] 保持原始雜亂樣貌（包含 LINE 訊息、電話隨手筆記、手寫轉打等）
  - [ ] 涉及個別會員個資與抱怨內容已做代號化（如甲會員、A 禮儀社）
