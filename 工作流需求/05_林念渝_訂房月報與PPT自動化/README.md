# 05 ｜ 林念渝：訂房月報與 PPT 自動化

## 📋 你的需求
客人需求 → 訂房作業 → 訂單建立 → 銷售資料登錄（ROW DATA）→ **資料彙整 → 報表統計 → PPT 製作** → 主管報告

希望將**粗體那三段**自動化，每月提供新的 ROW DATA，自動產出報表統計與 PPT。

---

## 🛠️ 建議工具：**專案**

### 這個需求非常適合自動化
原因：**輸入單純**（每月一份格式固定的 raw data）、**輸出明確**（報表 + PPT）、**每個月重複一次**。

---

## 📦 你要準備的素材
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **上月 raw data** | 從系統下載的原始銷售資料 | ★ 必備 |
| **上月報表** | 你現在交出去的那份 | ★ 必備 |
| **上月 PPT** | ⭐ **這份最重要**，它是結構範本 | ★ 必備 |
| **指標計算公式** | 住房率、ADR、RevPAR 各自怎麼算、小數幾位 | ★ 必備 |
| **raw data 欄位說明** | 每個欄位是什麼意思、哪些可以忽略 | ★ 必備 |
| 主管常問的問題 | 讓報告先一步回答 | 建議 |

> ⚠️ **請先去識別化**：客人姓名、電話、信箱要拿掉，訂單編號可保留，房型、通路、金額是分析必需的可以留。

---

## 🚀 建立專案步驟

1. 專案名稱：`訂房月報自動化`
2. **專案指令**：直接複製 [`專案指令.txt`](./專案指令.txt) 貼上。
3. **專案檔案**（最關鍵）：
   - 上月的 raw data
   - 上月的報表
   - 上月的 **PPT** ← ⭐ **這份最重要**（結構範本）

```
你負責製作訂房業務月報。

【指標】
住房率、ADR、RevPAR、通路佔比、月增率、年增率

【計算規則】
（逐項寫出公式，例如：住房率 = 已售房晚數 ÷ 可售房晚數 × 100，
 四捨五入到小數第 1 位）

【報表格式】
依專案內的上月報表範例

【PPT 結構】
依專案內的上月 PPT，頁面順序完全不變，只更換數字與說明文字

【規則】
1. 算不出來的指標請明說，不要用估計值填補
2. 與上月差異超過 20% 的項目，加上文字標註
3. 資料有缺漏時，明確指出缺哪一天、哪個欄位
```

---

## 🔄 每月操作步驟
提示詞檔案：[`每月操作提示詞.txt`](./每月操作提示詞.txt)

| 步驟 | 動作 |
|---|---|
| 1 | raw data **用貼的**（省上傳額度） |
| 2 | 輸入提示詞：「依專案指令產生本月報表」 |
| 3 | ★ **人工核對總營收、總間夜數與系統對帳** |
| 4 | 輸入提示詞：「依上月 PPT 結構產生本月 PPT，異常處加上文字說明」 |
| 5 | ★ 主管報告前人工潤稿 |

---

## ★ 第 3 步不能省

> 自動化最大的風險是「**錯得很有信心**」。每個月花兩分鐘核對兩個總數，可以擋掉九成的問題。
