# 01 ｜ 林良樹：工程監造照片白板辨識

## 📋 你的需求
施工照片中放有白板，記錄日期、施工項目、位置、施工人員／工種、機具、材料。希望承包商上傳照片後，AI 自動辨識白板文字、整理成結構化資料、依施工項目與日期分類照片，最後產生查驗紀錄初稿。是否符合圖說或規範，仍由監造人員判斷。

---

## 🛠️ 建議工具：**專案**

---

## 📦 你要準備的素材
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **白板欄位定義表** | 白板上每個欄位的正式名稱與填寫方式 | ★ 必備 |
| **施工項目清單** | 工程合約裡的項目代號與名稱，讓 AI 對照而非自創 | ★ 必備 |
| **查驗紀錄空白模板** | 你現在在用的那份表格 | ★ 必備 |
| **代表性照片 3–5 張** | 刻意包含：字跡清楚的、模糊的、手寫潦草的各一張 | ★ 必備 |
| 一份已完成的查驗紀錄 | 當作「正確答案」讓 AI 對照風格 | 建議 |

> 💡 **照片要故意挑爛的。** 只拿清楚的照片測試，你會高估它的辨識率，實際用在工地照片上就會出問題。

---

## 🚀 建立專案步驟

1. 專案名稱：`監造照片辨識`
2. **專案指令**：直接打開同目錄下的 [`專案指令.txt`](./專案指令.txt) 全選複製貼上。
3. **專案檔案**（上傳至專案資料庫）：
   - 白板欄位定義
   - 施工項目清單
   - 查驗紀錄空白模板

```
你負責辨識施工照片白板上的資訊。

【固定欄位】
檔名｜日期｜施工項目｜位置｜工種｜人員｜機具｜材料｜備註

【規則】
1. 看不清楚的欄位填「無法辨識」，絕對不要猜測
2. 手寫數字如有疑義，標註「疑似 X 或 Y」
3. 施工項目請對照專案內的項目清單，不在清單上的標「待確認」
4. 輸出 CSV 格式
```

---

## 🔄 操作步驟

1. 上傳照片（免費版每天約 3 張）
2. 得到 CSV 表格
3. ★ **監造人員檢查表格**，修正辨識錯誤
4. 貼回修正後的表格，請它套用查驗紀錄模板產生初稿
5. ★ **監造人員判斷是否符合圖說與規範**，簽核

---

## ⚠️ 這個需求有三個地方做不到

| 做不到的事 | 為什麼 | 怎麼辦 |
|---|---|---|
| 一次處理 20 張照片 | 免費版每天只能傳約 3 個檔 | 升級方案，或分批處理 |
| **自動搬移電腦裡的照片** | **ChatGPT 碰不到你的硬碟** | 它只能給你「建議的分類清單」，實際搬檔要人工做，或請它寫一段腳本 |
| 判斷是否符合圖說規範 | **這是專業責任** | **永遠由監造人員判斷** |

---

## ★ 最重要的一句話

> **「看不清楚的填『無法辨識』，絕對不要猜測」**
>
> 白板手寫字辨識率不穩定。沒有這句話，AI 會產出看起來很合理、但完全是編的資料——**而這種錯誤最難被發現。**
