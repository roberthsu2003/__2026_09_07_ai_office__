# 10 ｜ 玲靜：上市櫃同業分析比較表

## 📋 你的需求
做一份上市櫃同業分析比較表：當月 vs 上月、當月 vs 去年同期、今年 vs 去年累計。比較表包含差異及差異率、備註差異原因、按營收金額排名跟小計。希望可以生成互動式網頁。

---

## 🛠️ 建議工具：**專案**

---

## 📦 你要準備的素材
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **同業名單與股票代號** | 你要比較哪幾家，代號一併列出 | ★ 必備 |
| **13 個月的營收資料** | 要算年增率就必須有去年同期，所以是 13 個月不是 12 個月 | ★ 必備 |
| **現在在用的比較表** | 你的排版、欄位順序、小計位置 | ★ 必備 |
| **公司的數字規則** | 單位（仟元／百萬元）、四捨五入到第幾位 | ★ 必備 |
| **差異原因的常見類型** | 一次性業外、併購、基期異常、產業淡旺季…… | 建議 |

> 💡 **為什麼是 13 個月？**
> 要做「當月 vs 去年同期」，你需要去年的那一個月；要做「今年累計 vs 去年累計」，你需要去年一整年。一開始就把資料抓齊，不然做到一半才發現缺，又要重來。

> 💡 **「差異原因的常見類型」是進階但很值得的素材。**
> 把你們產業常見的原因先列成清單，AI 產「待查清單」時就會更精準，不會給你一堆不相干的查證方向。

---

## 🚀 建立專案步驟

1. 專案名稱：`同業月營收分析`
2. **專案指令**：直接複製 [`專案指令.txt`](./專案指令.txt) 貼上。
3. **專案檔案**：同業名單代號、現在用的比較表範本、差異原因常見類型清單。

```
你負責製作上市櫃同業月營收分析。

【同業名單】（列出公司名稱與代號）

【計算規則】
- 差異金額 = 本期 − 比較期
- 差異率 = (本期 − 比較期) ÷ 比較期 × 100，四捨五入到小數第 1 位
- 比較期為 0 或空值時，差異率填「不適用」，
  不要填 0，也不要略過該列

【排序】
依本期營收金額由大到小，最後加一列「小計」

【規則】
- 數字直接取自我提供的資料，不要自行推算或補值
- 資料有缺漏時明確指出缺哪一家、哪個月份
```

## 🔄 三步驟操作流程

### 第一步：產生四張比較表
提示詞檔案：[`步驟1_產生比較表提示詞.txt`](./步驟1_產生比較表提示詞.txt)

```
以下是 5 家同業 13 個月的營收資料（單位：仟元）：
（貼上表格）

請依專案指令產生四張比較表：
1. 當月 vs 上月
2. 當月 vs 去年同期
3. 今年累計 vs 去年累計
4. 綜合排名表

每張表欄位：公司名稱｜本期｜比較期｜差異金額｜差異率(%)
```

---

### 第二步：★ 這是整份講義最重要的一招（差異待查清單）
提示詞檔案：[`步驟2_差異待查清單提示詞.txt`](./步驟2_差異待查清單提示詞.txt)

如果你直接問「為什麼營收掉這麼多」，ChatGPT 會給你一堆看起來很專業的原因——**而那些原因很可能是編的**。它不知道這些公司實際發生了什麼事。

**改成這樣問：**

```
針對差異率絕對值超過 20% 的項目，請產生一份「待查清單」。

【重要】不要推測或斷定差異原因。你不知道這些公司發生了什麼事。

請改為列出「要查證什麼」，例如：
- 需確認 X 公司該月是否有一次性業外收入
- 需確認是否有併購或處分子公司
- 需確認去年同期是否有特殊事件造成基期異常

格式：公司｜項目｜差異率｜建議查證方向（可多項）
```

> 🎯 **把「給我原因」改成「給我待查清單」，就把 AI 從一個編故事的人，變成一個研究助理。**
> 這一招適用於所有「我需要知道為什麼」的場合。
> **真正的原因由你查證後填入——那才是你的專業價值。**

---

### 第三步：互動式網頁
提示詞檔案：[`步驟3_互動網頁產出提示詞.txt`](./步驟3_互動網頁產出提示詞.txt)

```
請產生一個單一 HTML 檔的互動式比較表：

- 不需要伺服器，用瀏覽器直接開啟就能用
- 所有資料寫在 HTML 裡，不要連外部網路
- 功能：依欄位排序、依公司篩選、差異率為負數時顯示紅色
- 上方加一個長條圖顯示各公司本月營收
- 手機也要看得清楚
```

**你不需要看懂 HTML。** 重點是知道：**你可以要一個「打開就能用的檔案」，而不只是一段文字。**

---

## ⚠️ 一定要驗算

> **用計算機驗證至少一個差異率。**
> 它算錯的機率不低，而錯誤的數字放進報告裡，後果由你承擔。
