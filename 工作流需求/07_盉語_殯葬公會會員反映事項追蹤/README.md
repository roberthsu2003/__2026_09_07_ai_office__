# 07 ｜ 盉語：殯葬公會會員反映事項追蹤

## 📋 你的需求
每天收集會員反映資料，**每 15 天為一期**。理監事定期會議（每三個月，1／4／7／10 月）時，整理出會員這三個月反映的事情，以及殯葬處**有處理**與**沒處理**（需持續追蹤）的部分，一併報告。

---

## 🛠️ 建議工具：**專案**

### 這個需求有個很大的優勢
你的輸入是 **LINE 訊息、電話筆記、紙本記錄**——全部都是**文字**。

**全程用貼的，完全不佔上傳額度。** 免費版做這個毫無壓力。

---

## 📦 你要準備的素材
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **事項分類清單（確定版）** | 先定好分類，不要邊做邊改 | ★ 必備 |
| **一期的原始記錄** | 保持原本的雜亂樣貌，不要先整理過 | ★ 必備 |
| **過去的理監事會報告** | 讓 AI 學你們的格式與措辭 | ★ 必備 |
| 會員名冊 | 用代號或簡稱即可，方便比對重複反映 | 建議 |

> 💡 **原始記錄不要先整理過。**
> 你如果先幫它整理乾淨，等於沒測到它真正的能力；
> 實際使用時你還是會拿到一堆雜亂的 LINE 訊息。
> **拿最亂的那一期來測，才知道它撐不撐得住。**

> ⚠️ **會員姓名建議用代號**（甲會員、A 禮儀社），涉及個別會員的抱怨內容尤其要注意。

---

## 🚀 建立專案步驟

1. 專案名稱：`會員反映追蹤`
2. **專案指令**：直接複製 [`專案指令.txt`](./專案指令.txt) 貼上。
3. **專案檔案**：事項分類清單、過去的理監事會報告範本。

```
你是殯葬公會的行政助理，負責整理會員反映事項。

【固定欄位】
編號｜反映日期｜反映會員｜事項分類｜內容摘要｜
是否已轉殯葬處｜處理狀態｜最新回覆｜下次追蹤日

【事項分類】只能從以下選擇：
場地設施／規費收費／證照與資格／流程行政／勞資人事／其他
不符合的一律歸「其他」，不要自創新分類。

【處理狀態】只能是：已處理／處理中／未處理

【規則】
1. 資料不足的欄位一律填「未提供」，
   絕對不要推測或補上沒有的資訊
2. 同一議題重複出現時合併為一筆，
   內容摘要末尾標註「（第 N 次反映）」
3. 輸出用 Markdown 表格
```

---

## 🔄 每 15 天做一次
把當期收集到的雜亂記錄**直接貼進去**（LINE 訊息、電話筆記、手寫轉打的都可以），得到標準表格。

**每一期存成一份獨立記錄，另外維護一份累積總表。**

---

## 📅 每季做一次（1／4／7／10 月）
提示詞檔案：[`季報告產出提示詞.txt`](./季報告產出提示詞.txt)

```
以上是本季六期的彙整資料。請產生理監事會報告：

一、本季概況（總筆數、各分類件數）
二、已處理事項
三、處理中事項
四、未處理需持續追蹤事項
   ★ 這一段請按反映次數由多到少排序
五、反映次數最多的前三項議題

【用詞】保持中性客觀，不要對殯葬處的處理效率下評語。
```

---

## ★ 這一案的成功關鍵是紀律，不是技巧

> **每一期都用同一份表格。**
>
> 只要格式一致，累積六期之後產生季報告是一瞬間的事。如果每期格式都不一樣，到時候要花更多時間整理。
