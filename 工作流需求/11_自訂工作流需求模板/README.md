# 11 ｜ 自訂工作流需求模板（待補學員專用）

## 📋 填寫你的工作流需求
若你尚未提交具體的工作流案例，請複製同目錄下的 [`工作流需求填寫模板.txt`](./工作流需求填寫模板.txt) 進行填寫：

```
【我的工作是】

【目前的流程】
（從哪裡開始 → 中間經過哪些步驟 → 最後產出什麼）

【最花時間的環節是】

【我希望 AI 幫我做的是】

【一定要人來判斷的是】
```

> 💡 **最後兩項特別重要。**
> 想清楚「哪些能交出去、哪些不能」，比想清楚「AI 有多強」更有用。

---

## 📦 你要準備的素材思考表

在補完需求描述之後，請依以下三類素材進行自我檢視與盤點：

| 素材 | 問自己 | 建議存放處 |
|---|---|---|
| **📗 規則類** | 這件事有哪些固定規則？欄位定義、計算公式、分類清單、格式規範、禁用詞？ | 專案指令 / 專案檔案 |
| **📘 範例類** | 我手上有沒有「做好的成品」可以當範本？（上個月的報表、滿意的貼文、模板） | 專案檔案（效益最高） |
| **📙 資料類** | 每次要處理的東西是什麼？多大？什麼格式？（CSV、白板照片、雜亂文字） | 對話輸入 / 當次貼上 |

---

## 🎯 決策三問（開始前先自我評估）

```
1. 這件事會再做第二次嗎？     → 決定用【對話】還是【專案】

2. 資料在我手上嗎？           → 決定要不要用【外掛程式】

3. 這件事出錯，誰負責？       → 決定哪些環節必須留給人
```
