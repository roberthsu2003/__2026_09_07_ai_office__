# 05 ｜ 林念渝：素材準備檢核表

上課前請逐項確認素材是否已經準備好：

### 📗 規則類（放進專案檔案 / 專案指令）
- [ ] **指標計算公式** ⭐必備：住房率、ADR、RevPAR、通路佔比、月增率、年增率各自公式與小數點規定。
- [ ] **raw data 欄位說明** ⭐必備：原始系統報表中各欄位代表意義、哪些可略過。
- [ ] 主管常問問題清單（建議）：可先引導 AI 加入報告注意事項。

### 📘 範例類（放進專案檔案）
- [ ] **上月 PPT** ⭐⭐⭐整案最關鍵核心：結構範本，供 AI 嚴格對照頁面順序與版面。
- [ ] **上月報表** ⭐必備：目前交給主管的正式月報 Excel 或表格範例。
- [ ] 上月的 raw data：作為對照組驗證。

### 📙 資料類（每次上傳／貼上）
- [ ] **本月原始銷售資料（raw data）** ⭐必備：
  - [ ] 已將客人姓名、電話、Email 去識別化
  - [ ] 保留訂單編號、房型、通路、金額等分析必要欄位
