## 📦 你要準備的素材
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **實價登錄 CSV** | 從內政部網站下載，不用先整理 | ★ 必備 |
| **關注的區域／社區清單** | 你實際在看的路段、社區名稱 | ★ 必備 |
| **異常值排除標準** | 什麼樣的資料算不合理、該剔除 | ★ 必備 |
| **過去的比價表範例** | 你現在怎麼做比價，讓 AI 照著做 | 建議 |
| 你關心的判斷問題 | 例如「這個社區現在算貴還是便宜」 | 建議 |

> 💡 **「異常值排除標準」比你想的重要。**
> 實價登錄裡有很多會扭曲平均值的資料：親友間買賣、含車位未分開計價、法拍屋、預售轉單。
> **沒排除掉，你算出來的行情就是錯的。** 先想清楚你的判斷標準，再交給 AI 執行。

## 🚀 建立專案步驟

1. 專案名稱：`實價登錄分析`
2. **專案指令**：直接複製 [`專案指令.txt`](./專案指令.txt) 貼上。
3. **專案檔案**：關注區域與社區清單、異常值排除規則表、過去比價表範例。

```
你負責分析實價登錄資料。

【資料清洗規則】
1. 排除「車位」單獨交易的紀錄
2. 排除總價或坪數為空值的紀錄
3. 排除單價明顯異常的紀錄（低於區域中位數 30% 或高於 300%），
   但要另外列出被排除的清單讓我確認

【固定分析】
1. 依單價排序（高到低）
2. 每坪價格的分位數（25%／50%／75%）
3. 同社區、同路段的比價表
4. 本期 vs 上期的價格變化

【規則】
- 不要推測價格變化的原因，改列「建議查證方向」
- 樣本數少於 5 筆的區域，明確標註「樣本不足，僅供參考」
```

## ⚠️ 第 3 項為什麼做不到

**ChatGPT 免費版無法自己去內政部網站下載檔案，也無法定時排程執行。**

側邊欄雖然有「排程」，但要理解它的作用：

> 🎯 **「排程」解決的是「什麼時候做」，不是「誰去做」。**
>
> 它可以在每月 1 號提醒你「該去下載實價登錄資料了」，但**它不會自己去下載**。

---

## 💡 建議的實際做法

**人工每月下載一次 CSV（約 5 分鐘）→ 貼進專案 → 自動產出分析**

每個月花 5 分鐘手動下載，換來後面全自動的分析，這個交換划算得很。**不要為了追求 100% 自動化，卡在第一步什麼都做不了。**
（若之後要做到真正的定期自動更新，需要用外部自動化工具例如 n8n 串接爬蟲或 API。）
