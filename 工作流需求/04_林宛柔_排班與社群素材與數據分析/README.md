## 需求 4-1：服務業人力排班

### 建議工具：**對話**

為什麼不用專案？因為每週的人力狀況都不一樣，資料變動太大，做成專案效益不高。而且**全部用貼的，完全不佔上傳額度**。

### 📦 4-1 素材準備
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **員工清單** | 代號、可上班時段、技能證照、每週時數上限 | ★ 必備 |
| **班別時間定義** | 早中晚各是幾點到幾點 | ★ 必備 |
| **硬性規則清單** | 法定的（工時、休假）＋ 店內的（每班幾人、證照需求） | ★ 必備 |
| **上週實際班表** | 讓 AI 知道你們平常怎麼排 | 建議 |

> 💡 **員工用代號就好**（A、B、C 或小名），不需要真實姓名。

### 4-1 一次到位的提示詞
提示詞檔案：[`4-1_服務業人力排班提示詞.txt`](./4-1_服務業人力排班提示詞.txt)

```
請幫我排下週（週一至週日）的班表。

【人員】
A：週一至週五可，早班優先，有咖啡師證照，每週上限 40 小時
B：僅週末可，每週上限 16 小時
（……照此格式列出所有人）

【班別】
早班 07-15、中班 11-19、晚班 15-23

【硬性規則】
1. 每班至少 2 人，其中至少 1 人有咖啡師證照
2. 同一人不可連續上晚班後接隔日早班
3. 不可超過個人每週時數上限
4. 每人每週至少休 1 天

【輸出】
1. 七天班表（表格：日期／早班／中班／晚班）
2. 每人本週總時數
3. ★「規則檢查」區塊：逐條說明是否符合。若有無法滿足的規則，
   明確指出是哪一條、缺什麼人力
4. 不要為了排滿而違反規則，人力不足就直接說人力不足
```

- ★ **第 4 條是關鍵**：你必須允許 AI 說「做不到」。不加這句話，它會硬排出一張看起來完整、但其實違規的班表。
- ⚠️ **它常常算錯總時數**：每次都要自己核對一下。
- ★ **最後的決定權在你**：排班牽涉勞基法、人情、體力狀況。**AI 只出草案，決定的是店長。**

## 需求 4-2：素材整合快速上架社群

### 建議工具：**專案（產內容）+ 其他工具（上架）**

### 📦 4-2 素材準備
| 素材 | 說明 | 必要性 |
|---|---|---|
| **品牌調性描述** | 你的語氣是活潑、專業、還是溫暖？舉三個形容詞 | ★ 必備 |
| **禁用詞清單** | 不能出現的字眼（誇大用語、競品名、法規敏感詞） | ★ 必備 |
| **表現好的貼文 3 篇** | 過去成效最好的，讓 AI 學你的風格 | ★ 必備 |
| **本次素材清單** | 拍了什麼、主題、想傳達的重點、活動日期 | ★ 必備 |
| 各平台字數限制 | IG、FB、官網各自的長度習慣 | 建議 |

> 💡 **「表現好的貼文」是這一案最有價值的素材。** 與其描述「我要活潑一點的語氣」，不如直接給它三篇你滿意的貼文。

### ChatGPT 做得到的（產內容包）
提示詞檔案：[`4-2_社群素材多格式產出提示詞.txt`](./4-2_社群素材多格式產出提示詞.txt)

```
以下是這次的素材資訊：
（貼上：拍了什麼、主題、想傳達的重點、活動日期）

請一次產出：
1. IG 貼文文案（含 hashtag，繁體中文，口語）
2. FB 貼文文案（比 IG 長，可以說故事）
3. 官網文章標題 3 個版本
4. 短影音腳本（15 秒、30 秒各一版）
5. 封面圖建議文字（不超過 12 字）

【語氣】（描述你的品牌調性）
【禁用詞】（列出不能出現的字眼）
```

### ChatGPT 做不到的
❌ **自動上架到 IG / FB**（ChatGPT 碰不到外部系統與平台後台，需靠自動化工具如 n8n 或人工排程發布）。

## 需求 4-3：官網 + FB + IG 數據交叉分析

### 建議工具：**專案（分析）**

| 環節 | 能不能做 |
|---|---|
| **從 GA4 / Meta 商務套件取得資料** | ❌ ChatGPT 拿不到，要人工匯出或串接 API |
| **交叉比對、找異常、給行銷切入點** | ✅ **這是 ChatGPT 最強的地方** |

> 🎯 **重點觀念：紅燈在「取數」，綠燈在「解讀」。**
> 資料一旦到手，後面的分析 ChatGPT 做得非常好。

### 📦 4-3 素材準備
| 素材 | 說明 | 必要性 |
|---|---|---|
| **三平台指標對照表** | 官網、FB、IG 的指標名稱不同，要自己先對應好 | ★ 必備 |
| **各平台匯出的 CSV** | 建議至少 6 個月，才看得出趨勢 | ★ 必備 |
| **行銷活動時間表** | 哪個月做了什麼活動、投了多少廣告 | ★ 必備 |
| 你想找出的問題 | 例如「為什麼社群熱度高但官網沒流量」 | 建議 |

> ⚠️ **指標對照表一定要自己做，AI 幫不了你。** 官網「工作階段」、FB「觸及」、IG「瀏覽次數」定義不同，搞錯對應關係，分析全部失真。

### 建立專案
1. 專案名稱：`跨平台成效分析`
2. **專案指令**：直接複製 [`4-3_跨平台成效分析專案指令.txt`](./4-3_跨平台成效分析專案指令.txt) 貼上。

```
你負責官網、FB、IG 的跨平台成效分析。

【指標對應】
三個平台的指標名稱不同，對照如下：
（列出：官網的 X = FB 的 Y = IG 的 Z）

【分析框架】
1. 三平台流量／互動趨勢比較
2. 找出「官網高但社群低」與「社群高但官網低」的內容
3. 標出異常波動（超過前三期平均 ±30%）

【規則】
1. 不要推測波動原因，改列「建議查證方向」
2. 三平台指標定義不同、不可直接比較時，明確說明
3. 資料不足時直接說不足，不要用估計值填補
```

### 操作方式
每月從各平台匯出 CSV → **貼進專案**（不要上傳，省額度）→ 得到分析。
