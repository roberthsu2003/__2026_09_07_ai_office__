# 第一部分：ChatGPT 的三個工具

大部分人用 ChatGPT 只用到「開一個對話問問題」。但要把工作**流程化**，你需要認識三個工具。

## 工具一：對話

開一個新對話，問完就結束。

**什麼時候用**：這件事只做一次，或每次的條件都不一樣。

## 工具二：專案

在左側選單點「專案」→ 新增。專案可以放兩樣東西：

- **專案指令**：你的規則寫一次，之後每次對話都自動套用
- **參考檔案**：範例檔、對照表、模板，釘在這裡不用重傳

**什麼時候用**：這件事**每個月或每週都要做一次**，而且規則不變。

> 💡 **這是本課程的重點。** 大部分同學的需求都適合用專案。

## 工具三：外掛程式

左側選單的「外掛程式」。它可以讓 ChatGPT 連到外部系統，去拿你手上沒有的資料。

一個外掛程式裡面可能包含**技能**、**應用程式**（就是連到 Gmail、雲端硬碟這類系統的整合）。

**什麼時候用**：資料**不在你手上**，要去別的系統拿。

---

## 怎麼選？照這個流程走

```
這件事會再做第二次嗎？
│
├─ 不會 ──────────────────→ 用【對話】
│
└─ 會
   │
   └─ 資料在我手上嗎？（我能複製貼上或上傳）
      │
      ├─ 在 ───────────────→ 用【專案】
      │
      └─ 不在（要去別的系統拿）→ 用【外掛程式】
                                │
                                └─ 外掛也拿不到？
                                   → 這件事 ChatGPT 做不到，
                                     需要換工具或人工處理
```

**把這張圖記起來。** 之後你遇到任何工作，都可以用它判斷該怎麼下手。

# 第二部分：免費版的限制，以及怎麼繞過

## 你必須知道的限制

免費版**看起來**跟付費版幾乎一模一樣——側邊欄的選單長得差不多，功能名稱也一樣。

**但額度差很多。** 你不會從畫面上看出來，只會在做到一半時突然被擋住。

| 項目 | 免費版 |
|---|---|
| 對話中上傳檔案 | **每天約 3 個檔**（尖峰時段可能更少） |
| 專案內的檔案 | 每個專案約 5 個檔（**這是另外算的**） |
| 檔案庫儲存空間 | 500 MB |
| 較強模型的訊息數 | 每幾小時十則左右，用完會自動換成較弱的模型 |
| 資料分析、網頁搜尋 | 有，但有用量限制 |

> ⚠️ **這些數字會變動，也可能因時段調整。請以你自己帳號當下看到的為準。**

### 怎麼確認自己是哪個方案
看左下角的帳號區塊：免費版會顯示「免費版」和一個「升級」按鈕。**這是唯一可靠的判斷位置。**

### 額度用完會怎樣
- **上傳檔案被擋**：會跳出訊息告訴你今天不能再傳了
- **訊息額度用完**：不會被擋，但**回答會突然變短、變弱**

> ⚠️ **這一點特別容易誤會。** 很多人以為是自己提示寫壞了，拼命改提示詞，其實只是模型降級了。**如果 ChatGPT 突然變笨，先想想是不是額度用完了。**

---

## 六個省額度的技巧

1. 1️⃣ **能貼文字就不要傳檔**：表格、清單、文字資料直接貼對話框，不佔上傳額度。
2. 2️⃣ **檔案放「專案」，不要放對話**：專案檔案額度另外算，釘在裡面可重複使用。
3. 3️⃣ **善用「檔案庫」**：點「+」從檔案庫取用已上傳或產出的檔案，不必重傳。
4. 4️⃣ **範例檔只放一次**：把成品範本放進專案，勝過五百字文字描述。
5. 5️⃣ **一則提示講完，不要聊天式來回**：把要求一次寫完整（要什麼、格式、規則、輸出）。
6. 6️⃣ **先建好專案，再開始工作**：規則與檔案到位後，每次只要貼入新資料。

# 素材：這件事決定你的成敗

**大部分人做不出好結果，不是提示詞寫得不好，是素材沒準備。**

- 📗 **規則類（放專案指令）**：欄位定義、計算公式、分類清單、格式規範、禁止事項。
- 📘 **範例類（放專案檔案）**：上月成品、歷史報表、滿意貼文、空白模板。（投報率最高）
- 📙 **資料類（每次貼上或上傳）**：當期 raw data、這批照片、最新記錄。（務必去識別化）

# 第四部分：三種紅燈

課程中你會不斷遇到「這個 ChatGPT 做不到」。**分清楚這三種紅燈，是這門課最重要的收穫：**

- 🔴 **額度紅燈**（如每天限傳 3 檔）：功能存在但額度受限 ➔ **付費升級即可解決**。
- 🔴 **能力紅燈**（如無法碰硬碟、無法自發社群）：工具本身就不支援 ➔ **換工具（自動化工具如 n8n 或寫腳本）或人工處理**。
- 🔴 **責任紅燈**（如合約法務審閱、實單交易決策、查驗簽核）：出事責任在人 ➔ **永遠由專業人員把關，絕對不交給 AI**。

# 第五部分：常見狀況與課前檢查清單

### 三句最有用的提示
1. **「不確定的填『未提供』，絕對不要推測」** —— 防止 AI 編造幻覺。
2. **「做不到就直接說做不到，不要勉強生出結果」** —— 防止硬擠出錯誤答案。
3. **「不要推測原因，改列建議查證方向」** —— 將 AI 從編故事者轉為得力研究助理。

### 開始之前的檢查清單
- [ ] 我知道自己是哪個方案（看左下角）
- [ ] 我知道自己每天能傳幾個檔
- [ ] 我用流程圖判斷過，這件事該用對話、專案還是外掛
- [ ] **我的📗規則類素材準備好了**（欄位、公式、分類、格式）
- [ ] **我的📘範例類素材準備好了**（做好的成品、模板）
- [ ] **我的📙資料類素材準備好了，而且已經去識別化**
- [ ] 我想清楚了哪些環節**必須由人判斷**
- [ ] 我知道每次要驗證哪個數字
