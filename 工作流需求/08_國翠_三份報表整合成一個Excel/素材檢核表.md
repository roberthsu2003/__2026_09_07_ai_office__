# 08 ｜ 國翠：素材準備檢核表

上課前請逐項確認素材是否已經準備好：

### 📗 規則類（放進專案檔案 / 專案指令）
- [ ] **欄位改名對照表** ⭐必備：三份報表各自 原欄位名稱 → 目標新欄位名稱。
- [ ] **要保留／刪除的欄位清單** ⭐必備：三份報表各自篩選留存的欄位。
- [ ] 格式轉換規則（日期 YYYY-MM-DD、千分位、缺值補「-」等）。

### 📘 範例類（放進專案檔案）
- [ ] **目標格式範例（Excel）** ⭐⭐⭐整案最關鍵核心：你理想中產出的工作表版面（A/B/C/彙總表）。
- [ ] 一份人工過去做好的成品（建議）：供課堂逐格比對驗收。

### 📙 資料類（每次上傳／貼上）
- [ ] **系統原始報表 3 份** ⭐必備：原始檔未經手動修改之檔案（課堂上建議兩份用複製貼上純文字、一份用檔案上傳以節省額度）。
