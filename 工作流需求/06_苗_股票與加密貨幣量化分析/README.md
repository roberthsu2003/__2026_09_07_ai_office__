# 06 ｜ 苗：股票與加密貨幣量化分析

## 📋 你的需求
利用 AI 優化股票及加密貨幣的量化交易研究流程，從數據獲取、策略開發到回測評估：
1. **數據獲取與清洗**：台股／美股 K 線、加密貨幣鏈上數據、財報與市場新聞
2. **策略開發與程式實作**：把交易想法轉成可執行的量化模型
3. **策略回測與績效優化**：勝率、賺賠比、最大回撤、夏普比率

---

## 🛠️ 建議工具：**對話 → 專案**

---

## 📦 你要準備的素材
請參考同目錄下的 [素材檢核表.md](./素材檢核表.md)：

| 素材 | 說明 | 必要性 |
|---|---|---|
| **策略邏輯的文字描述** | 進場、出場、停損、部位大小，寫得越具體越好 | ★ 必備 |
| **慣用框架與版本** | Python 版本、Pandas / Backtrader / CCXT 的版本 | ★ 必備 |
| **歷史資料樣本** | 一小段 K 線資料，讓 AI 知道你的欄位格式 | ★ 必備 |
| **回測報告範例** | 你希望輸出哪些指標、什麼排版 | 建議 |
| 命名規則 | 變數、函式的命名習慣，讓程式碼風格一致 | 建議 |

> 💡 **「策略邏輯的文字描述」是這一案的核心素材。**
> 你腦中很清楚的規則，寫出來常常會發現有模糊地帶——
> 例如「跌破均線賣出」是指收盤跌破，還是盤中觸及就賣？
> **把這些講清楚，AI 才寫得出你要的程式。**

## 💻 ChatGPT 很擅長的部分 ✅

### 1. 把交易邏輯翻成程式碼
提示詞檔案：[`交易邏輯轉程式提示詞.txt`](./交易邏輯轉程式提示詞.txt)

```
請把這個交易邏輯寫成 Python（使用 Pandas 和 Backtrader）：

【進場】20 日均線向上突破 60 日均線
【出場】收盤價跌破 20 日均線，或停損 -8%
【部位】每次投入總資金的 20%

請加上詳細註解，並說明每個參數的意義。
```

### 2. 程式除錯
貼上錯誤訊息，請它定位問題並提供修正。

### 3. 解讀回測報告
提示詞檔案：[`解讀回測報告提示詞.txt`](./解讀回測報告提示詞.txt)

```
以下是回測績效報告：
（貼上數據）

請分析：
1. 這個策略在什麼市況下表現最好、最差
2. 最大回撤發生在哪個期間，可能的原因
3. 這份績效有沒有過度擬合的跡象

【重要】不要推測你看不到的市場事件，
若需要外部資訊才能判斷，請明說「需確認 XXX」。
```

### 4. 參數優化架構
請它提供參數最佳化的程式架構，並說明如何避免過度擬合。

## ❌ ChatGPT 做不到的部分

| 自動下單 | **這超出本課程範圍** |
